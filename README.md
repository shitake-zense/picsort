# ピクソート 0.17 — 写真整理ツール

## ダウンロード

[ピクソート 0.17 のダウンロードページ](https://github.com/shitake-zense/picsort/releases/tag/v0.17.0)から、お使いのパソコンに合うZIPを選べます。

- Windows：`PixSort-v0.17-Windows.zip`
- Mac（Apple Silicon / Mシリーズ）：`PixSort-v0.17-Mac-Apple-Silicon.zip`
- Mac（Intel）：`PixSort-v0.17-Mac-Intel.zip`

ZIPを展開してから起動してください。Mac版は署名・公証されておらず、実機での画面操作は未確認です。

JPEG・PNGの写真を、目で確認しながら仕分けるためのデスクトップアプリです。
写真・作業記録はPC内だけで扱い、初回起動からインターネット接続は不要です。

## 起動

Windows版ZIPをすべて展開し、`PixSort-v0.17-Windows.exe`を起動してください。`_internal`はアプリと同じフォルダに置きます。
Windowsではアプリの隣の`PixSortData`に作業記録を保存するため、書き込み可能な場所で使ってください。Mac版は `~/Library/Application Support/PixSort` に保存します。

Mac向けのソースとビルド手順は同梱しています。Mac版アプリのビルド・実機確認はまだ行っていません。

## フォルダの移動と振り分け先

右上の「フォルダを開く」で作業するフォルダを選びます。右上の「更新」またはF5で、外部で追加・変更された写真とサブフォルダを再読み込みできます。候補や表示位置はできる限り維持します。
候補の写真が見つからない場合は画面下に件数を表示し、候補の記録は残します。そのフォルダにあるサブフォルダは左の一覧に表示されます。
一覧でダブルクリック、または選択して「開く」で中に入れます。「↑ 親フォルダへ」で一つ上に戻ります。
「＋ フォルダを作成」で、現在開いているフォルダの中に新しいフォルダを作り、振り分け先に追加します。9件の上限時はフォルダのみ作成し、画面下に知らせます。
「↑ 親を振り分け先に追加」を押せば、間違えて中に入れた写真を親フォルダへ戻す候補を付けられます。
一覧のフォルダを選択して「行き先に追加」を押すと、写真の移動・コピー先として登録できます。
別の場所は「移動先フォルダを追加」で指定できます。新しく開くフォルダでは振り分け先は空です。
一度設定した振り分け先と作業状況はフォルダごとに保存され、戻ると再表示されます。

写真一覧には、開いているフォルダ直下の写真を表示します。親フォルダに写真がなくても、中のフォルダに入って作業できます。
旧版でサブフォルダ内の写真に未反映の候補を付けていた場合は、元のフォルダでその候補も表示します。
フォルダを移動しても未反映の候補は保存され、元のフォルダに戻ると確認できます。

## 写真を見ながら操作

| 操作 | 動作 |
|---|---|
| 写真番号 → Enter | 番号を入力して、現在の絞り込み内の写真へ移動。2枚比較では操作対象だけを移動 |
| 左クリック / ← | 前の写真へ。クリックまたは矢印の長押しで連続送り |
| 右クリック / → | 次の写真へ。クリックまたは矢印の長押しで連続送り |
| Shift＋左クリック | クリックした写真を削除候補にして次へ |
| Ctrl＋左クリック | クリックした写真の削除・振り分け候補を解除。大きな写真、下のサムネイル、チェック一覧で利用可 |
| 最初の写真へ / Home | 最後の写真でボタンを表示。現在の絞り込み内の最初に戻る |
| マウスホイール | 写真のポインターのある位置を拡大・縮小 |
| F11 / 画面右上の全画面 | アプリの操作画面を含めて全画面にする。F11またはEscで戻る |
| ホイール押し込み / Esc | 写真を全画面表示 / 通常画面へ戻す。全画面中のホイール押し込みでも戻る |
| 拡大中の左ドラッグ | 表示位置を移動 |
| Z / 原寸で確認ボタン | ピントを原寸で確認し、「画面に合わせる」で全体表示に戻す |
| 設定した振り分けキー | 移動先を指定して次へ。初期設定は1〜9 |
| X / Delete | 削除候補にして次へ |
| H | 保留にして次へ |
| 0 | 操作対象の候補指定を解除 |
| Ctrl+Z / Macでは⌘Z | 直前の候補指定を取り消す。一括指定もまとめて戻る |

1枚表示の下には、現在の写真を中央に、前の写真を左、次の写真を右に、最大3枚ずつ表示します。
サムネイルに「前」「現在」「次」を表示し、端の写真では空欄を設けて中央の位置を変えません。
振り分け予定の写真には［行き先の頭文字］を表示します。同じ頭文字の行き先は［ス1］［ス2］のように区別し、左の振り分け先にも同じ記号を表示します。
「チェック一覧」では離れた写真を選び、「チェックした写真を削除候補に」で一括指定できます。
写真をクリックし、別の写真をShift＋クリックすると、間の写真をまとめてチェックできます。別にチェックしていた写真はそのまま残ります。
一覧の「画像サイズ」で小・中・大・特大を選べます。選んだサイズは次回起動時も保持されます。
振り分け予定の写真には行き先の名前、削除候補には「削除候補」と表示します。1枚表示や2枚比較でも表示中の写真の名前の横に行き先が出ます。
一覧やサムネイルにマウスを置くと、行き先のフルパスを確認できます。
チェックした写真に振り分けキーを押すと、まとめて行き先を指定できます。
削除候補をチェックして「チェックした削除候補を解除」（または0キー）を押すと、一括解除できます。「取り消す」で戻せます。

## 2枚比較

Alt+2または「2枚比較」で隣り合う写真を並べます。写真番号を入力した場合、操作対象の側だけが移動します。操作したい側にマウスを置くと、枠と「操作対象」が表示されます。
振り分けキー・X・H・原寸で確認ボタンはこの側に作用します。Shift＋左クリックはクリックした側を削除候補にします。
Ctrl＋左右矢印で操作対象の左右を選べます。Shift＋左右矢印では、操作対象だけを移動でき、もう片方をまたいで比較できます。矢印だけなら両方が移動します。
「左を固定」またはAlt+Pを押すと、左の写真を残したまま右の写真を送れます。ホイール拡大は左右別々に操作できます。
2枚比較中のホイール押し込みでも、2枚を並べたまま全画面になります。整理予定の写真には、ファイル名と振り分け先・削除予定などを重ねて表示します。
前後の写真は画面表示用に先読みします。写真の拡大時は、元画像の解像度で読み込みます。
先読みが間に合わない場合や、写真を初めて開くときは読み込みが表示されることがあります。

## Windowsの「プログラムから開く」

配布版の「プログラムから開くに追加.cmd」を実行すると、このユーザーのWindowsにピクソートを候補として登録します。
標準アプリは変更しません。写真を右クリックし、「プログラムから開く」→「別のプログラムを選択」からピクソートを選んでください。
初回は候補がすぐに出ない場合があります。その場合は「別のプログラムを選択」→「このPCで別のアプリを探す」でPixSort-v0.17-Windows.exeを選んでください。
選択した写真と同じフォルダが開き、その写真を表示します。同じ版のピクソートが起動中なら、その画面で開きます。
登録後にアプリのフォルダを移動した場合は、移動先から登録をもう一度実行してください。

## 振り分けキーの変更

左の移動先の右にある「設定」をクリックし、「キーを決める」を選んで使いたいキーを押します。
他の移動先や、削除・写真送りなどに使用中のキーは、その場で知らせます。
以前F11を振り分け先に登録していた場合、全画面操作に使用するため空いているキーに変更し、画面下に通知します。
設定は写真フォルダごとに保存されます。表示名と実際の行き先は「設定」で別々に変更できます。
すでに付けた候補の行き先は変更されないので、「整理を反映」の確認画面で確認してください。

## 整理を反映

候補指定の段階では写真を移動・削除しません。最後に「整理を反映」またはCtrl+Enterで確認画面を開きます。
削除と各振り分け先のタブにサムネイルが並びます。写真をクリックすると候補が解除され「解除済」と表示されます。もう一度クリックすると候補に戻ります。
解除した写真は反映対象から外れ、「解除を保存して戻る」を押しても解除が保存されます。後でアプリの「取り消す」でまとめて戻せます。
選んだ写真を大きく表示し、行き先を確認してから実行します。
右上で移動／コピーを選べます。コピーを選んでいても、削除候補はOSのごみ箱へ送ります。

- 同名ファイルは上書きせず、連番を付けます。
- コピー内容と元ファイルを確認してから移動元を取り除きます。
- ごみ箱が利用できない場合、アプリは完全削除に切り替えません。
- 処理できなかった写真は候補に残り、詳細をスクロールして確認できます。
- 確定後の移動先は「ファイル操作の履歴」、ごみ箱からの復元はOSのごみ箱で確認できます。
- アプリ外で候補指定後に変更された写真は処理されません。再確認して指定し直してください。

## 似た写真を探す

上部の「似た写真を探す」で、現在の一覧に表示中の写真をローカルで比較します。小さくした画像の構図・明暗・色の特徴を比較し、候補をグループにまとめます。写真の品質評価や自動削除はしません。

「撮影時刻＋構図」では指定した秒数以内かつ構図が近いものを探します。撮影時刻が記録されていない写真は対象外で、件数を表示します。「構図のみ」では撮影時刻を使わず全体を比較します。似ている度は3段階で変えられます。撮影時刻は写真の記録を使い、カメラの時計がずれていると同じ場面でも分かれることがあります。

グループを選び、写真をクリックしてチェック。Shift＋クリックで範囲をまとめてチェックできます。2枚をチェックして「比較」を押すと、検索結果を閉じずに2枚を並べられます。任意の枚数を削除候補や振り分け先に指定し、候補解除もできます。指定しただけでは元画像は変更されず、「整理を反映」で確認してから実行します。

右側の写真はホイールで拡大、拡大中の左ドラッグで位置を移動できます。左クリックで前、右クリックで次、Shift＋左クリックで削除候補、Ctrl＋左クリックで候補解除です。写真にマウスを置いて、振り分け先キー・X・H・0・Zや矢印キーも使えます。比較中はCtrl＋左右矢印で操作する側を切り替え、Shift＋左右矢印で片側だけ移動します。

「全画面」またはF11で似た写真の画面を広げ、写真上のホイール押し込みまたはCtrl+Fで写真だけを全画面にできます。Escで戻ります。Shift＋右クリックまたは「次のグループ」で次の候補グループに進みます。写真によっては似ていないものが混ざったり、近い写真が別グループになったりするので、必ず目で確認してください。

画面の幅が狭いときは、プロパティ・切り抜き・似た写真の検索を上部の「ツール」にまとめています。

## 写真の情報と切り抜き

上部の「プロパティ」で、画像サイズや撮影日時、カメラ・撮影設定など、記録されている情報を確認できます。
「切り抜き」では左ドラッグで範囲を選び、右ドラッグで選択範囲を移動できます。ホイールで拡大・縮小し、拡大中はホイール押し込みドラッグで表示位置を移動できます。グリッドはON/OFF可能です。自由・1:1・4:3・3:2・16:9を選べ、長方形の比率は「縦長に変更」「横長に変更」で向きを切り替えられます。F11は編集画面全体、ホイール押し込みまたはCtrl+Fは写真を全画面にし、Escで戻ります。写真だけの全画面では、比率の向き・グリッドの変更と保存もできます。「保存先を選ぶ」でフォルダを指定でき、次回以降も記憶します。「元のフォルダ」で初期設定に戻せます。元画像は変更せず別ファイルを保存し、同名ファイルは上書きしません。JPEGは再圧縮され、EXIF等は可能な範囲で引き継ぎますが、一部の付加情報は失われることがあります。元画像は保管してください。

## 画面の幅の調整

画面の縦の境界線をドラッグして幅を調整できます。通常画面のサイドバーと2枚比較、似た写真のグループ・一覧・プレビューと2枚比較、整理内容の確認画面に対応しています。幅と切り抜きのグリッド設定は、このパソコンの作業データに保存されます。

## 保存・引き継ぎ

Windowsでは作業状況は`PixSortData/sessions.sqlite3`、最後に開いたフォルダは`PixSortData/settings.json`に保存されます。Macでは`~/Library/Application Support/PixSort`内の同名ファイルに保存されます。
同じ場所に旧版`PixSort-v0.16-Windows`（またはそれ以前の版）があり、新版に作業記録がまだない場合は、新版の初回起動時に旧版の記録を自動でコピーします。
切り替えるときは旧版を閉じてから新版を起動し、その後は新版で作業を続けてください。
別の場所にある旧版から引き継ぐ場合は、旧版の`PixSortData`（KOMAでは`KomaData`）を、新版アプリの隣に`PixSortData`という名前でコピーします。
アプリを閉じた状態でコピーしてください。写真データはこのフォルダには含まれません。
配布時は、個人の作業記録を含まない配布用ZIPを使用してください。

## 対応範囲

Windows 11 x64で検証した試作版です。Mac版はMacでのビルド・実機検証が必要です。RAW・RAWとJPEGのペア管理は未対応です。
一覧は撮影時刻順ではなく、ファイル名順です。
ごみ箱に入らない場所やアクセス権がない場所では、その写真の処理がエラーになります。

## ソースから起動・ビルド

Python 3.12を推奨します。開発ライブラリの初回取得にはネット接続が必要ですが、完成したアプリの実行には不要です。

```sh
python -m venv .venv
```

Windowsは`.venv\Scripts\activate`、Macは`source .venv/bin/activate`で仮想環境を有効にします。

```sh
python -m pip install -r requirements.txt
python app.py
python build.py
python -m unittest discover -s tests -v
```

Windowsは`dist/PixSort/PixSort.exe`、Macは`dist/PixSort.app`が生成されます。Mac版はMacでビルドしてください。
Mac向けのコード署名・公証は含まれません。テストは専用の一時画像だけを操作します。
